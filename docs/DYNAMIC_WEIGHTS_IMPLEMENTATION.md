```python
    """動的重み調整クラス"""
```

#### 品質メトリクス

| メトリクス | 計算方法 | 範囲 |
|-----------|---------|------|
| **harmonic_persistence** | HPSS後のharmonic energy比率 | 0-1 |
| **high_freq_ratio** | Mel Spectrogram高周波成分 | 0-1 |
| **percussive_ratio** | HPSS後のpercussive energy比率 | 0-1 |
| **quality_score** | 重み付き平均 | 0-1 |

#### 品質スコア計算式

```python
quality_score = (
    harmonic_persistence * 0.50 +  # 最重要
    high_freq_ratio * 0.30 +
    (1.0 - percussive_ratio) * 0.20
)
```

```python
class MoisesDBIntegrator:
    def __init__(
        self,
        db_path: Path,
        midi_output_dir: Path,
        sr: int = 22050,
        use_gpu: bool = False,
        dynamic_weights: bool = False  # ← 追加
    ):
        if dynamic_weights:
            self.weight_adjuster = DynamicWeightAdjuster(sr, use_gpu)
    
    def generate_audio_chordmap_yaml(
        self,
        song_dir: Path,
        output_yaml_path: Path,
        merged_wav_paths: Optional[Dict[str, Path]] = None  # ← 追加
    ):
        # 動的重み調整適用
        if self.dynamic_weights and merged_wav_paths:
            adjusted_weights = self.weight_adjuster.generate_weighted_chordmap(
                stem_paths=merged_wav_paths,
                output_yaml=output_yaml_path
            )
```

## 🔧 技術詳細

### 重み調整アルゴリズム

```python
def adjust_weights(stem_types, qualities, base_weights):
    adjusted = {}
    
    for stem_type in stem_types:
        base_weight = base_weights[stem_type]
        quality_score = qualities[stem_type]['quality_score']
        
        # 調整係数計算
        if quality_score < 0.4:  # 低品質
            adjustment = (quality_score / 0.4) * 0.5
        elif quality_score > 0.7:  # 高品質
            adjustment = 1.0 + (quality_score - 0.7) * 0.5
        else:  # 中品質
            adjustment = 1.0
        
        adjusted[stem_type] = base_weight * adjustment
    
    # 正規化（合計1.0）
    total = sum(adjusted.values())
    adjusted = {k: v / total for k, v in adjusted.items()}
    
    return adjusted
```
